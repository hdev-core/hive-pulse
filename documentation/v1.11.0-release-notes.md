# HivePulse 1.11.0 — Release Notes

## 🛡️ Scam Shield, massively expanded

HivePulse now checks every transfer, delegation, and Hive-Engine token send against **~15,000 known scam and watchlisted accounts** — up from ~900. The list is compiled from the community **watchmen** aggregator (condenser, denser, Ecency, HiveWatchers, mahdiyari), the same sources the wider Hive ecosystem trusts.

Two clearly-separated tiers so warnings stay honest:
- **Known scam accounts** → a hard, red block: "funds sent here are not recoverable" (overridable only with an explicit tick, for the rare false positive).
- **Watchlisted accounts** → a softer amber caution: flagged by HiveWatchers for abuse, not confirmed fund theft — worth a look before you send.

Impersonation warnings (a look-alike of an account *you* have paid before) and the red/amber tags in the recipient autocomplete are unchanged.

## ✍️ Post Analyzer works on the new Ecency editor

Ecency rebuilt its `/publish` page as a two-step editor, which had stopped the SEO + GEO analyzer from reading your post correctly. Fully restored:
- **Title, body, tags, and description** are detected again on Ecency's new editor.
- Your score is **remembered across both steps** — writing (step 1) and tags (step 2) — so it no longer drops when you move to add tags.
- **InLeo** benefits too: it shares the same editor engine, so headings, links, and images are now scored accurately there as well.

## 🐛 Fixes & polish

- Post Analyzer correctly reconstructs headings, links, and images from rich-text (WYSIWYG) editors instead of missing them.
- Hardening so the editor changes don't affect PeakD, hive.blog, 3Speak, or Actifit — all verified working.
