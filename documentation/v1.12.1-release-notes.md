# HivePulse 1.12.1 — Release Notes

A focused fix release on top of 1.12.0.

## 🔌 Your chosen RPC node now actually works

HivePulse ships a picker with nine Hive nodes and six Hive-Engine nodes — but only three of them were ever permitted to be contacted. The rest failed silently with a network error, which showed up as **"Failed to fetch stats"** whenever the extension fell back to a spare node or you selected one yourself in Settings.

All fifteen nodes are now reachable: `api.deathwing.me`, `api.openhive.network`, `hiveapi.actifit.io`, `techcoderx.com`, `api.syncad.com`, `rpc.mahdiyari.info`, `api.c0ff33a.uk`, `hive.atexoras.com`, plus the Hive-Engine nodes `v6-he.atexoras.com`, `herpc.actifit.io`, `he.c0ff33a.uk` and `herpc.dtools.dev`.

> **Why the browser asks about new permissions.** These are the public Hive API nodes already listed in HivePulse's own node picker. They had to be declared up front for the browser to allow the connection. No new kind of data is accessed — this simply lets the node you already chose respond.

## ✍️ Alt text has to describe the image

The Post Analyzer used to accept *any* alt text on an image. It now only counts alt text that actually describes the picture, so these no longer earn the Media points:

- `![](url)` — empty
- `![image](url)` — a generic placeholder word
- `![IMG_1234.png](url)` — an auto-filled filename

Most editors drop the filename in for you, so this was quietly inflating scores against what search engines and screen readers actually see once the post is published. Write `![a hiking trail at sunset](url)` instead.

The wording throughout the panel now says **"need descriptive alt text"** rather than "missing alt text", and the ⓘ explainer spells out which forms don't count — the old message read as wrong to anyone whose editor had already filled something in.

Contest note: judging re-scores every entry from the blockchain with the same rule, so rankings are unaffected. A screenshot taken before this release may read a few points higher than the final table.
